# Dušan Stoiljković — Portfolio

A standalone, dependency-free portfolio website (HTML/CSS/JS). No build step required.

## Run it
Just open `index.html` in any modern browser, or deploy the whole folder to any static host
(GitHub Pages, Netlify, Vercel, Cloudflare Pages, etc.).

## Features
- EN / SR / DE language toggle (remembers your choice via localStorage)
- Sticky nav that gains a blurred dark background on scroll
- Scroll-reveal animations on each section
- Sections: Hero, About, Skills, Experience, Career direction, Projects, CV, Contact
- Real GitHub project links (github.com/DusanStoiljkovic)

## Placeholders to fill in
- **CV files** — the two "Download CV" buttons in the CV section link to `#`. Replace `href="#"`
  with the path to your `cv-en.pdf` / `cv-de.pdf`.
- **Email** — currently `dusan.stoiljkovic@email.com` in the Contact section. Update to your real address.
- **Featured project image** — the Cinema Microservices card shows a placeholder pattern with
  `[ architecture diagram ]`. Swap in a real screenshot if you have one.
- The project thumbnails (`[ store UI ]`, `[ website ]`, `[ terminal / API ]`) are placeholders too.

## Files
- `index.html` — the whole site
- `uploads/profilna.jpeg` — your portrait (used in the About section)
